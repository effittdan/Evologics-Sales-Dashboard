# Evologics Sales Analytics Design System

## Product Character

Sales Analytics is a quiet operational tool for administrators, salespeople,
and distributor viewers. Optimize for scanning, comparison, repeat use, and
trust in the underlying data.

## Foundation

- Primary green: `#1F4F45`
- Secondary green: `#4F7D6D`
- Sidebar green: `#183D36`
- Gold accent: `#C9B27E`
- Canvas: `#EDF3EF`
- Surface: `#FFFFFF`
- Warm surface: `#EFEBE2`
- Border: `#D9E4DE`
- Text: `#252A2A`
- Muted text: `#6F7775`
- Body type: Inter 400/500
- Labels: IBM Plex Sans 600

## Layout And Components

- Keep the 264px desktop navigation rail and collapse it above the content on narrow screens.
- Use 8px radii for controls, panels, and cards.
- Keep filters global and visible above analytical views they affect.
- Use cards only for individual metrics, charts, tables, reports, and framed tools.
- Use icons for navigation and familiar utility actions; label unfamiliar actions.
- Keep headings compact inside dashboard panels and reserve larger type for the application title.

## Data States

- Show shared-ledger freshness and errors in concise status strips.
- Never imply a remote view is live until the source acknowledges the current data payload.
- Keep empty, loading, unauthorized, and filtered-to-zero states explicit.
- Preserve normalized transaction definitions across every chart, table, report, and map.
